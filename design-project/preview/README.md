# Preview cards

Focused review surfaces for the BikeNest design system. Open each in a browser; each card loads preserved assets or source files where available.

| Card | Shows | Loads preserved files |
| --- | --- | --- |
| `colors-primary.html` | Full OKLch palette with hex fallbacks, semantic freshness scale, badge pairings | tokens from `colors_and_type.css` |
| `typography-specimens.html` | Display/body/mono scale with live specimens and rules | `colors_and_type.css` |
| `spacing-tokens.html` | Spacing units, radii, elevation | `colors_and_type.css` |
| `components-buttons.html` | Buttons, fields, cards, badges, queue table | recipes from `colors_and_type.css`; applied kit link |
| `brand-assets.html` | Wordmark, all 7 preserved photos, all 25 Lucide icons | `assets/imagery/*`, `build/icons/*` |
| `applied-ui.html` | Render-check thumbnails + live iframes of source screens | `render-checks/*.png`, `p1/p2/p3/m1` source screens |

Suggested review order: colors-primary → typography-specimens → spacing-tokens → components-buttons → brand-assets → applied-ui.
